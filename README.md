# Segue downloads

Segue is a native radio automation player for **macOS 14 Sonoma or later**, built by Vincent Rio Servidad. The installer supports **Apple Silicon and Intel**.

**[Download the latest version](https://github.com/vinceservidad/segue-releases/releases/latest)**

Segue provides automated music transitions, a media library, scheduling, instant players, tempo controls and broadcast-style dynamics. Music analysis and playback run locally on your Mac.

## Install or update

1. Download the DMG from the latest release and open it.
2. Quit the old copy of Segue, then drag Segue into Applications and replace the old app. Your existing library is retained.
3. The free build is ad-hoc signed and is not notarized by Apple. If macOS blocks the first launch, attempt to open it, then use System Settings → Privacy & Security → Open Anyway. On macOS 14, you can also right-click the app and choose Open.

Each release includes a SHA-256 checksum file. This repository distributes compiled installers and release notes, not Segue's development source.
